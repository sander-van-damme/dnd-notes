# Modelresultaten

Zet hier de resultaten die je wilt vergelijken. **Er is geen verplicht template of vaste mapstructuur.** Een map per gebruikte tool/model is handig, maar kies de indeling die bij je experiment past.

Bewaar bij voorkeur de **originele, onbewerkte uitvoer**. Vermeld waar mogelijk modelversie, instellingen, audiobestand en datum; ontbrekende gegevens hoeven geen blokkade te zijn. Je kunt later analyses of extra runs toevoegen.
